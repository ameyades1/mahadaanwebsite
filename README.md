# Antar Yog Mahadaan

Website for Mahadaan, the donation initiative of the Antar Yog Foundation, Mumbai.

**Live site:** https://ameyades1.github.io/mahadaanwebsite/

The pages in `docs/` are a static export of the WordPress build, served by GitHub Pages (branch `main`, folder `/docs`). Don't edit them by hand: change the site in WordPress, run `export.sh` from the `wp-mahadaan` project, then commit and push `docs/`.
